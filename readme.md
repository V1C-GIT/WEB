## 🔍 Overview
T&T Paparazzi is designed to showcase professional photography services, provide company background information, and allow clients to log in or interact with the agency. The application features a clean, responsive layout complete with navigation menus, service breakdowns, and authentic brand storytelling.

---

## 📁 Project Structure
The repository consists of the following core HTML documents and asset directories:
* `index.html` — Homepage featuring the primary brand introduction and a user authentication/login portal.
* `About.html` — Company background, mission statement, and core motto (*"Capturing moments. Creating memories."*).
* `Services.html` — Detailed breakdown of offered packages including Event, Portrait, Brand & Business, and Lifestyle photography.
* `css_assets/style.css` — Global styling and layout rules (referenced across all HTML files).
* `_images/` — Directory holding branding logos, icons, and gallery/page graphics.

---

## ✨ Features & Pages
* **Interactive Navigation Bar:** Present on all pages for seamless switching between Home, About, Services, Contact, and Enquiries.
* **Authentication Portal:** Built right into the homepage (`index.html`) for user logins and sign-up redirection.
* **Social Integration:** Embedded icon links for quick access to social networks (Instagram, Skype, Facebook, Google).


---

## 🛠️ Technologies Used
* **HTML5:** Semantic markup for page structure.
* **CSS3:** Custom styles for layout, typography, and visual presentation.
* **Ionicons:** Vector icon library utilized for social media buttons.
